# Excel 報價資料層實作計畫

## Slice 1：契約與模板定義

- 記錄 AI 固定輸出格式。
- 將 CNS、一般架、船用的工作表、明細列與合計儲存格轉成可讀設定。
- 驗證 JSON 靜態檔可正常解析。

## Slice 2：SQLite schema

- 建立方案、品項、方案品項與規則版本資料表。
- 建立 AI 請求、圖片選擇、報價與報價明細快照資料表。
- 寫入三種方案及模板的基礎資料。

## Slice 3：驗證

- 以真實 SQLite 啟動 Spring context。
- 驗證資料表、外鍵、方案與模板。
- 執行完整 Maven 測試。

## Risks

- 正式空白模板可能與目前範例座標不同：模板定位以資料列保存，收到正式模板後可更新。
- 船用計算未提供：schema 先支援內部／客戶可見列，不猜測公式。
- 圖片批次界線未定：資料模型支援多圖，收集規則延後。
