# 銷售：模式專屬測試

每次先取消舊草稿。以下全為合成測試資料；固定價格與列數只適用本套件隔離主檔，請先看[主檔前提](../README.md#固定主檔前提)。

## 1. 初始輸入

```text
#報價 銷售
公司：範例測試公司（虛構）
工程：零件銷售
業務承辦：測試承辦甲
聯絡人：測試聯絡人乙
電話：0000000000
銷售支架，規格合成商品 A，單位組，單價120.50，數量10；銷售連接件，規格合成商品 B，單位個，單價33.33，數量12；贈送護套，規格合成贈品，單位個，單價0，數量2。備註均為合成測試，不得用於交易。
```

或另開新草稿，私訊上傳[對應 CSV](../csv/sales-complete.csv)。CSV 抽取不呼叫模型。

## 2. 模式規則與預期

小計1604.96、稅額80.25、總額1685.21（5%）；3筆動態商品明細完整呈現，包含0單價贈品；單號依銷售範本顯示 S 前綴。價格只取自使用者輸入，不回寫主檔；無圖時不強制圖片決策。

## 3. 修改

按最新卡片的修改，再傳：

```text
只把銷售支架數量從10改成4，其他保持不變。
```

預期：小計881.96、稅44.10、總額926.06；另外兩筆保留，贈品金額仍為0。

## 4. 邊界與產檔

另開草稿省略商品單價：必須追問，不可參考前一單猜價；3筆商品正常呈現。

完成必要欄位與圖片決策，核對預覽後用最新卡片確認；檢查 XLSX、PDF、單號、日期及下載內容。這是待執行的實機腳本，不是實機通過證據。
