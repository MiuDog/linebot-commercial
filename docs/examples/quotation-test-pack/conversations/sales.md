# 銷售：可貼到 LINE 的測試對話

每個案例使用新草稿，已有草稿時先按最新卡片的「取消」按鈕。所有人名與資料均虛構。

## 1. 一次提供完整資料

```text
#報價 銷售
公司：範例測試公司（虛構）
工程：功能驗收工程
業務承辦：測試承辦甲
聯絡人：測試聯絡人乙
電話：0000000000
新增以下兩筆自訂品項：
測試支架，規格合成規格 A，單位組，單價120.50，數量2，備註測試資料不得用於交易。
測試連接件，規格合成規格 B，單位個，單價33.33，數量3，備註測試資料不得用於交易。
```

預期：兩筆列金額為241.00、99.99；小計340.99，預設5%稅額17.05，合計358.04。
客戶明細與數量、單價一致。
若卡片要求確認臨時品項或補欄位，完成後才進入完整預覽。

## 2. 修改與補件

在最新預覽按「修改」，再傳：

```text
只把工程名稱改成「功能驗收工程第二版」，電話改成0000000001；測試支架數量改成4，其他欄位、另一筆品項與單價都保持不變。
```

預期：公司與承辦不被清空；小計581.99，稅額29.10，總額611.09。不要只檢查 AI 有回話，須比對最新預覽。

## 3. CSV 路徑

另開新草稿，在私訊上傳 [對應 CSV](../csv/sales-complete.csv)。預期與第1節相同，CSV 抽取不呼叫 AI。

## 4. 正式產檔

先確認預覽，再按最新卡片的確認按鈕；檢查同一單號的 XLSX、PDF、LINE摘要與下載連結。有效期限應為報價日加部署設定天數（預設15），不能用範例文字指定日期或單號。

品項不得新增回 CNS／GENERAL 固定主檔。

自然語言／OCR 結果需要真實模型驗收；本文件是輸入腳本，不是成功對話截圖。
