# 船用：模式專屬測試

每次先取消舊草稿。以下全為合成測試資料；固定價格與列數只適用本套件隔離主檔，請先看[主檔前提](../README.md#固定主檔前提)。

## 1. 初始輸入

```text
#報價 船用
公司：範例測試公司（虛構）
工程：船艙施工彙總工程
業務承辦：測試承辦甲
聯絡人：測試聯絡人乙
電話：0000000000
內部計價：船艙施工人工，規格合成工班，單位工時，單價800，數量12；船艙設備租用，規格合成設備，單位日，單價2500，數量2；船用運輸，規格合成運輸，單位趟，單價1800，數量1。備註均為合成測試，不得用於交易。
```

或另開新草稿，私訊上傳[對應 CSV](../csv/marine-complete.csv)。CSV 抽取不呼叫模型。

## 2. 模式規則與預期

小計16400.00、稅額820.00、總額17220.00（5%）；內部3筆計價明細，客戶可見明細為0筆，只交付彙總。三筆動態列合法，三筆動態品項合法。必須明確選圖或不提供圖片。

## 3. 修改

按最新卡片的修改，再傳：

```text
船艙施工人工數量改為10，其他保持不變。
```

預期：內部小計14800.00、稅740.00、總額15540.00；客戶文件仍不可露出人工、租用或運輸明細。

## 4. 邊界與產檔

尚未回答圖片問題時不可確認產檔；明確選「不提供圖片」才繼續。檢查 XLSX 與 PDF 都沒有內部明細。

完成必要欄位與圖片決策，核對預覽後用最新卡片確認；檢查 XLSX、PDF、單號、日期及下載內容。這是待執行的實機腳本，不是實機通過證據。
