# 空白：模式專屬測試

每次先取消舊草稿。以下全為合成測試資料；固定價格與列數只適用本套件隔離主檔，請先看[主檔前提](../README.md#固定主檔前提)。

## 1. 初始輸入

```text
#報價 空白
公司：範例測試公司（虛構）
工程：一次性維修統包工程
業務承辦：測試承辦甲
聯絡人：測試聯絡人乙
電話：0000000000
維修工程一式，規格合成統包範圍，單位式，單價12000，數量1，備註合成測試，不得用於交易。
```

或另開新草稿，私訊上傳[對應 CSV](../csv/blank-complete.csv)。CSV 抽取不呼叫模型。

## 2. 模式規則與預期

小計12000.00、稅額600.00、總額12600.00（5%）；直接使用使用者報的一式價格12000，只有1筆客戶可見工程明細；不得展開 CNS／一般架主檔。必須明確選圖或不提供圖片。

## 3. 修改

按最新卡片的修改，再傳：

```text
維修工程一式的單價改成13500，數量仍是1。
```

預期：小計13500.00、稅675.00、總額14175.00；只更新該動態列，不更動任何固定主檔。

## 4. 邊界與產檔

加到3筆動態工程項目仍合法；固定 itemCode 不適用。未回答圖片詢問不可直接產檔。

完成必要欄位與圖片決策，核對預覽後用最新卡片確認；檢查 XLSX、PDF、單號、日期及下載內容。這是待執行的實機腳本，不是實機通過證據。
