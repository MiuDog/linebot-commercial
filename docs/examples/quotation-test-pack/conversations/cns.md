# CNS 架：模式專屬測試

每次先取消舊草稿。以下全為合成測試資料；固定價格與列數只適用本套件隔離主檔，請先看[主檔前提](../README.md#固定主檔前提)。

## 1. 初始輸入

```text
#報價 CNS 架
公司：範例測試公司（虛構）
工程：CNS 固定主檔工程
業務承辦：測試承辦甲
聯絡人：測試聯絡人乙
電話：0000000000
外部鷹架 EXTERNAL_SCAFFOLD 數量100式；電梯閘門 ELEVATOR_GATE 數量1式。採用 CNS 已啟用主檔的價格，保留其他固定品項。
```

或另開新草稿，私訊上傳[對應 CSV](../csv/cns-complete.csv)。CSV 抽取不呼叫模型。

## 2. 模式規則與預期

小計1210.00、稅額60.50、總額1270.50（5%）；使用 CNS 主檔全 21 列；EXTERNAL_SCAFFOLD 單價 10、ELEVATOR_GATE 單價 210。其餘 19 列數量與複價必須空白，不是 0；CSV 不可提供固定品項單價。

## 3. 修改

按最新卡片的修改，再傳：

```text
明確刪除 ELEVATOR_GATE，其他固定列保持不變。
```

預期：小計1000.00、稅50.00、總額1050.00；內部與客戶明細剩20列，19列仍空白。

## 4. 邊界與產檔

臨時品項不限筆數，仍需完整填寫並確認。臨時品項不得寫回主檔。

完成必要欄位與圖片決策，核對預覽後用最新卡片確認；檢查 XLSX、PDF、單號、日期及下載內容。這是待執行的實機腳本，不是實機通過證據。

## 5. 臨時品項不限筆數

新草稿分別上傳[3筆臨時品項](../csv/cns-3-temporary.csv)及[250筆臨時品項](../csv/cns-250-temporary.csv)。預期均可通過：3筆小計30、稅1.50、總額31.50；250筆小計2500、稅125、總額2625。固定主檔仍全部保留且數量空白，臨時品項不得回寫主檔。檢查正式XLSX/PDF分頁，所有臨時列都在。

不限業務筆數不代表單次傳輸無上限：CSV保留1MiB大小限制，模型呼叫仍受token預算限制；大量資料優先使用CSV。
