# 一般架：模式專屬測試

每次先取消舊草稿。以下全為合成測試資料；固定價格與列數只適用本套件隔離主檔，請先看[主檔前提](../README.md#固定主檔前提)。

## 1. 初始輸入

```text
#報價 一般架
公司：範例測試公司（虛構）
工程：一般架獨立價格版本工程
業務承辦：測試承辦甲
聯絡人：測試聯絡人乙
電話：0000000000
外部鷹架 EXTERNAL_SCAFFOLD 數量80式；防塵網 DUST_NET 數量80式。價格依一般架已啟用主檔，保留其他固定品項。
```

或另開新草稿，私訊上傳[對應 CSV](../csv/general-complete.csv)。CSV 抽取不呼叫模型。

## 2. 模式規則與預期

小計3760.00、稅額188.00、總額3948.00（5%）；使用一般架自己的20列主檔及價格版本；本案例在隔離測試主檔將 EXTERNAL_SCAFFOLD 設為12、DUST_NET 設為35，與 CNS 不同。不得讀到 CNS 價格；不含 ELEVATOR_GATE。其餘18列保留空白數量與複價。

## 3. 修改

按最新卡片的修改，再傳：

```text
外部鷹架 EXTERNAL_SCAFFOLD 數量改為40，其他保持不變。
```

預期：小計3280.00、稅164.00、總額3444.00；仍使用一般架單價12，不可改用 CNS 的10。

## 4. 邊界與產檔

另開草稿指定 ELEVATOR_GATE：本測試主檔無此一般架品項，應要求澄清或拒絕固定碼，不可從 CNS 借用。臨時品項不限筆數，仍須逐筆驗證完整性並確認。

完成必要欄位與圖片決策，核對預覽後用最新卡片確認；檢查 XLSX、PDF、單號、日期及下載內容。這是待執行的實機腳本，不是實機通過證據。

## 5. 臨時品項不限筆數

新草稿分別上傳[3筆臨時品項](../csv/general-3-temporary.csv)及[250筆臨時品項](../csv/general-250-temporary.csv)。預期均可通過：3筆小計30、稅1.50、總額31.50；250筆小計2500、稅125、總額2625。固定主檔仍全部保留且數量空白，臨時品項不得回寫主檔。檢查正式XLSX/PDF分頁，所有臨時列都在。

不限業務筆數不代表單次傳輸無上限：CSV保留1MiB大小限制，模型呼叫仍受token預算限制；大量資料優先使用CSV。
