# 報價功能測試範例

本套件提供五種報價格式的可複製文字、可上傳 CSV、合成圖片，以及正常、邊界、失敗恢復與舊版相容案例。所有公司、聯絡人、品項與金額都是測試資料。

## 從這裡開始

1. 使用獨立測試 LINE Channel、資料庫與儲存 Bucket，依根目錄 [Docker 部署說明](../../../README.md) 啟動服務，啟用測試用公司資產。
2. 每個獨立案例從新草稿開始；已有草稿時使用最新卡片的「取消」，避免 CSV 合併到上一個案例。
3. 選下表任一格式，複製文字腳本，或直接在私人聊天室上傳對應 CSV。依提示補齊資料，確認臨時品項及圖片選擇。
4. 核對預覽後按最新卡片的「確認」，開啟 XLSX 與 PDF，檢查金額、欄位、圖片及分頁。
5. 依 [60 項功能矩陣](coverage-matrix.md) 執行其他案例，把結果、版本與證據填入 [執行紀錄](execution-record.md)。其中自動故障注入案例應執行所列測試，不必破壞真實服務來製造故障。

| 格式 | 文字腳本 | 可上傳 CSV | 格式特性 |
|---|---|---|---|
| CNS 架 | [CNS](conversations/cns.md) | [完整範例](csv/cns-complete.csv) | 獨立固定主檔；臨時品項不限筆數 |
| 一般架 | [一般架](conversations/general.md) | [完整範例](csv/general-complete.csv) | 獨立固定主檔；臨時品項不限筆數 |
| 船用 | [船用](conversations/marine.md) | [完整範例](csv/marine-complete.csv) | 動態品項、圖片決策，客戶文件只呈現彙總 |
| 空白 | [空白](conversations/blank.md) | [完整範例](csv/blank-complete.csv) | 動態品項、圖片決策 |
| 銷售 | [銷售](conversations/sales.md) | [完整範例](csv/sales-complete.csv) | 動態品項 |

五份主案例依模式分開；稅率均為5%。詳細修改、圖片決策與負面案例見各自腳本。

| 模式 | 專屬輸入及驗證 | 小計 | 稅額 | 總額 |
|---|---|---:|---:|---:|
| CNS | 固定外架100、電梯閘門1；21列中19列數量保持空白 | 1210.00 | 60.50 | 1270.50 |
| 一般架 | 自己的價格版本：外架12×80、防塵網35×80；20列、不含電梯閘門 | 3760.00 | 188.00 | 3948.00 |
| 船用 | 人工、設備、運輸3筆內部計價；客戶只見彙總、須圖片決策 | 16400.00 | 820.00 | 17220.00 |
| 空白／一式 | 維修統包1式；不展開固定主檔、須圖片決策 | 12000.00 | 600.00 | 12600.00 |
| 銷售 | 3筆商品含零價贈品；完整商品明細、S前綴單號 | 1604.96 | 80.25 | 1685.21 |

### 固定主檔前提

以上固定價格均是合成測試值，不是正式報價。自動測試載入 `src/test/resources/schema.sql`；CNS為21列、一般架為20列。**只在一般架完整主案例的記憶體資料庫**，將外架單價改12、防塵網改35，以確認不會錯用CNS價格。LINE實測須先在隔離資產版本設定同樣條件，或按現行主檔重算預期；不得修改正式價格配合範例。

CNS／一般架各提供3筆及250筆臨時品項CSV。筆數不限，臨時資料仍須完整與確認，不回寫主檔；250筆皆應保留並跨頁產出。此類大量輸入優先用CSV；單次CSV仍限1MiB，模型仍受token預算限制。

## CSV 範例與邊界

共 **38 份**：17 份可接受輸入、21 份預期拒絕輸入。檔名、預期解析結果及金額列在 [csv-manifest.json](csv-manifest.json)，自動測試會直接讀取交付的檔案。

- 正常案例：五種完整格式、兩種固定品項、零單價、四捨五入、引號／逗號／換行、缺少基本資料、200 筆品項、UTF-8 BOM。
- 錯誤案例：數量或價格不合法、必要品項欄位缺漏、固定碼誤用、未知／混用格式、表頭資料衝突、201 筆、固定品項覆寫、未知主檔碼、錯誤欄數／標題／引號及非 UTF-8。
- `sales-missing-header.csv` 可解析，但仍須補齊基本資料才能確認；「可解析」不等於直接產檔。
- `cns-standard.csv`、`general-standard.csv` 使用 [自動測試主檔](../../../src/test/resources/schema.sql) 的 EXTERNAL_SCAFFOLD 單價 10、DUST_NET 單價 50；數量 2、3，總額 178.50。這些是合成價格。LINE 實測應核對目前啟用的測試主檔，不能把此金額當成正式價格。
- CSV 會合併目前草稿；省略原有列不代表刪除。刪除操作請依矩陣使用修改流程。
- 除刻意損壞的 UTF-8 案例外均為 UTF-8。不要用 Excel 重新儲存錯誤案例，否則可能修正掉原本要測的錯誤。

## 圖片、按鈕與模型流程

[圖片使用說明](images/README.md) 提供 6 張合成 PNG：名片、規格表、含指令干擾的規格圖、橫向／直向候選圖、無法辨識圖片。圖片是輸入素材，並非成功對話或產檔證據。

矩陣涵蓋全部 8 種卡片動作、圖片選擇／移除／分頁、草稿修改／取消／確認、缺漏追問、金額與上限、重送及跨使用者隔離、XLSX／PDF／傳送失敗重試、下載權杖與公司資產版本。

模型案例包含 `AI_WORKFLOW_ENABLED=false` 的舊版流程，以及啟用後的 VISION、TEXT、ESCALATION 分工、有限升級、token 預算、逾時、checkpoint、重啟恢復及 API key 隔離。設定值由測試環境提供；範例不含憑證。文字或圖片辨識可能因模型而異，應核對結果，不應假設固定措辭。

## 自動驗證

在專案根目錄執行：

```powershell
# 直接驗證這 38 份 CSV、計價結果與案例引用
.\mvnw.cmd -q -Dtest=QuotationExamplePackTest test

# 包含既有邏輯與多模型流程的完整回歸
.\mvnw.cmd clean verify
```

新測試包含 38 個檔案案例及 1 個案例完整性檢查。解析／計價使用實際服務及隔離的 SQLite 合成主檔；無效編碼另驗證嚴格 UTF-8 解碼拒絕。案例完整性檢查驗證五種格式、八種動作及引用檔案存在，不代表 60 項 LINE 情境已實際執行。

自動測試不連真實 LINE 或模型供應商。所有實機紀錄初始為「未執行」；須完成 LINE、真實模型及實際文件檢查後才可標記通過。
