# LINE 實機範例

可直接操作的測試輸入見 [報價功能測試範例](quotation-test-pack/README.md)：五種格式、38 份 CSV、6 張合成圖片與 60 項功能驗收案例，附可填寫的執行紀錄。

目前尚未完成新版 Docker 的真實 LINE 對話與結果截圖，這裡不提供模擬截圖或沿用舊桌面版截圖作為驗收證據。

## 待錄製流程

1. 以獨立測試 Channel 連接新版 Docker 服務，驗證 webhook。
2. 商用機：建立報價、填寫虛構客戶與品項、確認預覽、生成並開啟 XLSX／PDF。
3. 文書機：上傳可公開的測試文件／圖片，執行查詢或整理，開啟生成結果。
4. 擷取實際聊天室與實際結果視窗，確認不含真實客戶、公司印章、憑證、私人對話或可使用的下載權杖。
5. 在此目錄保存經檢查的截圖，記錄測試日期、映像 digest、步驟與結果，並在根目錄 README 嵌入圖片後上傳 GitHub。

測試使用虛構資料不表示可以製作假對話；每張截圖必須來自實際成功執行的測試。
